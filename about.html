運営と制作について

「ちょっとヒマ」は個人で実装・保守しているブラウザ向けのゲーム・占いサイトです。定番のルールを使うゲームと、このサイト内で動く操作・得点表示を組み合わせています。すべてのゲームのルールを独自に考案したという意味ではありません。ソースはGitHubの13yh820/chotto-himaで確認できます。

公開する時は、遊び方と実装の一致、開始・終了・再挑戦、スマホの操作、戻る導線を確認します。不具合や説明の違いは修正履歴に残します。対応ブラウザや利用環境によって違いが出る場合があります。

サイトの目的と方針

本サイトは「ちょっとした空き時間を、気持ちよく潰せる場所をつくる」ことを目的としています。運営にあたっては次の3点を方針としています。

1. すぐ遊べること
アプリのインストールや会員登録を不要とし、ページを開いた瞬間から遊べる状態を保ちます。登録せずに遊べます。占いなどで必要な入力は各ページの説明をご確認ください。

2. 正確でわかりやすい説明を添えること
すべてのゲームに遊び方・上達のコツ・よくある質問を用意し、ルールを知らない方でもその場で理解して楽しめるようにしています。占いページにも、星座や運命数などの基礎知識をまとめた解説を掲載しています。

3. 占いはあくまで娯楽として扱うこと
本サイトの占いコンテンツは、エンターテインメントとしてお楽しみいただくものです。医療・法律・投資などの専門的な判断の根拠となるものではありません。結果は日々の話題づくりや、自分を見つめ直すきっかけとしてご利用ください。

お問い合わせ

ご意見・ご要望、不具合のご報告、その他お問い合わせは、GitHubリポジトリのIssuesページよりお寄せください。いただいた内容には、運営者が確認のうえ可能な範囲で対応いたします。

GitHub Issues からお問い合わせ

GitHub Issuesへの投稿にはGitHubアカウントが必要です。報告には「ゲーム名・端末/ブラウザ・行った操作・期待した結果・実際の結果」を添えてください。氏名・生年月日・支払情報などの個人情報を公開しないでください。返信や対応時期はお約束していません。

広告の掲載について

本サイトでは、サイトの運営・維持にかかる費用をまかなうためにGoogle AdSenseによる広告を掲載する場合があります。広告配信にあたってはCookieが使用される場合があります。詳しい取り扱いについてはプライバシーポリシーをご確認ください。
